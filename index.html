功能特性

一键置顶

鼠标悬停 + 快捷键，窗口瞬间置顶或取消

系统托盘

启动后最小化到托盘，不占任务栏空间

自定义快捷键

Ctrl / Shift / Alt / Win 任意组合

开机启动

设置后随系统自动启动，无需手动打开

轻量无依赖

纯 Rust 编写，单个 exe 文件，轻量高效

免管理员

普通用户权限即可运行，安全放心

使用说明

操作方式
置顶 / 取消置顶鼠标悬停在窗口上，按 Ctrl + Shift + T（默认）
左键快速切换左键点击托盘图标
修改快捷键右键托盘图标 → 修改快捷键 → 按下新组合键
开机启动右键托盘图标 → 开机启动（勾选即生效）
退出程序右键托盘图标 → 退出
