# PinIt

全局窗口置顶切换工具 — 将鼠标悬停在任意窗口上，按快捷键即可置顶/取消置顶。

## 功能

- **一键置顶**：鼠标悬停在目标窗口上，按下快捷键即可切换置顶状态
- **系统托盘驻留**：启动后自动最小化到系统托盘，不占用任务栏空间
- **自定义快捷键**：支持 Ctrl / Shift / Alt / Win 组合任意按键
- **开机启动**：可设置随系统自动启动
- **轻量无依赖**：纯 Rust 编写，单文件可执行，无需运行库

## 使用说明

| 操作 | 方式 |
|------|------|
| 置顶/取消置顶 | 鼠标悬停在窗口上，按 `Ctrl+Shift+T`（默认） |
| 修改快捷键 | 右键托盘图标 → 修改快捷键 → 按下新组合键 |
| 开机启动 | 右键托盘图标 → 开机启动（勾选即生效） |
| 退出程序 | 右键托盘图标 → 退出 |
